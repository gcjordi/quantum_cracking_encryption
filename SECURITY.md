# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| < 2.0 | No |

The pre-v2 code is retained only in Git history and should not be treated as maintained software.

## Scope

Quantum Cryptography Lab is educational software. It deliberately operates on tiny demonstration moduli and is **not** a production cryptographic library.

A valid security report may concern the Python package, optional Gradio UI, notebooks, repository automation, dependency handling, or a vulnerability introduced by project code. The expected mathematical fact that sufficiently capable fault-tolerant quantum computers threaten RSA is not itself a vulnerability in this repository.

## Responsible use

Use the project only with systems, keys and data that you own or are explicitly authorized to test. The examples included in this repository generate deliberately small toy values.

## Reporting a vulnerability

Please do **not** publish exploit details, credentials, private keys or sensitive information in a public issue.

If GitHub displays a **Report a vulnerability** option in the repository Security area, use that private channel. Otherwise, contact me privately through my GitHub profile before disclosing technical details publicly.

I will assess reports in context of the project's educational scope and coordinate disclosure when a project vulnerability requires a fix.
